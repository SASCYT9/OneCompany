# Покупка частинами mono — підготовка OneCompany

Перевірено 3 жовтня 2026. Це окрема інтеграція від plata by mono. Її не
увімкнено; заявки клієнтам, платежі та повідомлення банку не створювалися.

## Підключення та технічний сценарій

Потрібні погодження магазину в mono, його `store-id` та окремий секрет.
API підписує оригінальні байти JSON через HMAC-SHA256/Base64. Наші UUID й
ідемпотентність мають зберігати одну банківську заявку на одну спробу замовлення.
Callback перевіряється підписом; статус можна додатково прочитати через API.

Після згоди покупця `WAITING_FOR_STORE_CONFIRM` означає очікування дії магазину.
Підтвердження `/api/order/confirm` прив'язане до видачі товару. У документації є
3–25 платежів. Тестування починається в sandbox; приклади облікових даних іншого
магазину зі stage-документації не використовуємо.
[Джерело: API mono](https://monobank.ua/api-docs/chast).

## Комісія та маржа

Публічна мінімальна комісія продавця — 2,9%. Вона залежить від строку, стягується
одноразово; перекладати її на покупця не дозволено. Після повернення товару за
межами 14 днів комісія продавця не повертається. Повну погоджену тарифну сітку
OneCompany треба отримати від банку, а не підставляти рекламний мінімум для всіх
строків. [Джерело: умови продавця](https://monobank.ua/chast/vendors).

Формула внеску після банківської комісії: `P × (1 − f) − C`, де `P` — сума
продажу, `f` — погоджена комісія, `C` — усі включені в розрахунок витрати.

Умовний продаж 10 000 грн із витратами 8 000 грн:

| Комісія | Комісія, грн | Залишається після C і комісії | Частка від P |
|---|---:|---:|---:|
| 2,9% — публічний мінімум | 290 | 1 710 | 17,1% |
| 5% — сценарій, не тариф банку | 500 | 1 500 | 15% |
| 10% — сценарій, не тариф банку | 1 000 | 1 000 | 10% |

Це арифметичні сценарії, не фактична маржа SKU. Для товару потрібні закупівельна
ціна, окремий курс постачальника, доставка/імпорт, податки та реальний тариф ПЧ.
Товар зі слабкою маржею може мати менше частин або бути виключений із сервісу.
[Пояснення mono щодо маржинальності](https://monobank.ua/knowledge-base/chast/marketing/product).

## Що письмово підтвердити для товарів під замовлення

1. Чи допускається імпорт із очікуванням 30/60/90+ днів після згоди покупця?
2. Скільки може тривати `WAITING_FOR_STORE_CONFIRM`? 15-хвилинний тайм-аут
   відповіді покупця з документації не є відповіддю на строк імпорту.
3. Що банк вважає видачею при доставці: відправлення чи отримання покупцем?
4. Коли продавець отримує гроші та чи може використати їх для закупівлі до видачі?
5. Що робити при затримці, відсутності товару, зміні курсу й скасуванні?
6. Які строки/комісії/ліміти будуть погоджені саме для OneCompany?

До відповіді банку не пропонувати ПЧ для довгого імпорту. Пілот готувати для
підтвердженої наявності та перевіреної маржі; окремо прийняти сценарії відмови,
дубльованої заявки, callback, видачі й часткового/повного повернення.
