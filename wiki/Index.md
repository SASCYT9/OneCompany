# OneCompany — project vault

> Supporting and historical context. Current code, `AGENTS.md`, and
> `.agents/PROJECT_CONTEXT.md` take precedence when information conflicts.

This Obsidian vault stores decisions, brand research, incident notes, and screenshots
that do not belong in source code. Open the repository's `wiki/` directory as a
vault on the current machine; no absolute machine path is canonical.

## Sections

- [[Shop/README|Shop]] — shop architecture notes and cross-brand decisions.
- [[Brands/README|Brands]] — source research and supplier/brand caveats.
- [[Dev/README|Dev]] — incidents and development investigations.

## Conventions

- Use `PascalCase` or `Kebab-Case` filenames without spaces.
- Prefer Obsidian wikilinks internally and Markdown links for external URLs.
- Put screenshots in `screenshots/` as `YYYY-MM-DD-context.png`.
- Common tags: `#shop`, `#brand/<name>`, `#bug`, `#decision`.
- Date claims and distinguish observations from active production guarantees.

Agents should write here only when the user explicitly asks for wiki documentation
or a repository-wide documentation refresh.
